# 玄历 v0.5.0

在线地址：https://yangjunjie0226-bot.github.io/YJJ/

免费的本地计算 iPhone PWA，出生资料继续使用 `xuanli.profile.v1`，不上传服务器。

## v0.5

- 10 类神煞：天乙贵人、文昌、禄神、羊刃、驿马、桃花、华盖、将星、天德、月德。默认折叠；每条列起例、目标、命中柱与流派。天乙采用甲戊庚牛羊表，羊刃采用五阳干帝旺，阴干不作无刃结论。神煞不进入吉凶分值。
- 调候扩展首批核对甲木寅、辰、巳、午、未、申、酉、戌月的辅助条文。未覆盖组合明确留空。甲未、甲戌与旧主干简表不同，显示差异并停止该主干加权。不是全量调候古籍引擎。
- 动态模型：本命扶抑首位2、其余1，格局相神各1，主调候2；流年/月/日供给权重1/2/3，各半分给天干与地支本气。候选动态分=本命分/(1+流运供给)，并列第一全部保留。冲突五行排除颜色推荐。此为明确的现代辅助模型，不是古籍定量公式，不把供给当吉凶。藏干十神展示，不重复计量；尚未模拟合化与大运叠加。
- 极端/从格边界与出生交节不确定时暂停综合及动态推荐。无时辰仅按已知三柱暂算。日历使用所选日12:00截面，年以立春、月以节切换。
- Service Worker 全量缓存成功后切换，在线打开及回到前台检查更新；离线保留上次完整版本。更新不删除 localStorage，编辑中的资料不会被自动刷新打断。

## 源码及验证

可审查源码在 `src/`。`.deploy/` 是旧基础静态资源压缩包，构建先解包再以 `src/*` 覆盖；旧 `src-overrides/` 仅为历史留档，工作流不再使用。历法库锁定 lunar-javascript 1.7.7，构建时下载到站点，本机运行无需 CDN。

Actions 执行全部 JavaScript 语法检查、17组规则/缓存测试、真实历法交节边界和30天动态计算、资源完整性检查，然后发布 Pages。

规则来源与口径：
- [三命通会·卷三](https://zh.wikisource.org/zh/三命通會/卷三)：禄、驿马、天乙、天月德、羊刃。其余为程序明确列出的通行查表，不将吉凶断语编码。
- [穷通宝鉴](https://zh.wikisource.org/zh/穷通宝鉴)：三春、三夏、三秋甲木中明确辅助干，按段落保留条件与差异。复杂古文条件尚未自动确认。

所有取用、颜色和宜慎仅为文化参考，显示计算依据，不保证现实结果。
