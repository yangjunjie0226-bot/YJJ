# 玄历 · iPhone PWA 万年历 / 八字个人日历

这是一个面向 iPhone 的免费 PWA 日历原型，可通过 Safari「添加到主屏幕」使用。

## 当前能力
- 公历、农历、干支、节气与传统黄历信息
- 出生资料与基础八字四柱
- 流年/流月/流日与原局的合冲刑害等结构关系
- 本地保存出生资料
- PWA / Service Worker / 深色模式

## 原则
历法与干支采用固定算法；喜用神、格局、旺衰、调候、幸运色和个人宜忌不会随机生成，在确定命理体系后再作为可复算规则引擎加入。

传统八字属于传统术数体系。本项目可做到历法数据与所选规则一致、可复算，但不把命理判断描述为经现代科学验证的确定预测。
